# 局域网狼人杀 MVP 游戏规则

## 1. 基础设定

- 阵营分为狼人阵营和好人阵营。
- 好人阵营包括村民和神职。
- 神职包括预言家、女巫、守卫、猎人和白痴。
- 死亡后不公开身份，游戏结束时统一公开所有身份。
- 死亡玩家不能正常发言、投票、聊天或执行技能。
- 所有关键行动和随机行为由服务端执行。

## 2. 夜间流程

每夜固定顺序：

```text
狼人讨论并刀人
→ 预言家查验
→ 守卫守护
→ 女巫用药
→ 统一结算
→ 判断胜负
```

默认时长：

- 狼人讨论：90 秒。
- 预言家行动：30 秒。
- 守卫行动：30 秒。
- 女巫行动：30 秒。

主机可在开局前设置，也可在对局中动态调整。

公共屏幕在整个夜间只显示“夜间行动进行中”和公开倒计时，不显示当前具体角色阶段，避免泄露身份。

## 3. 狼人规则

### 3.1 私密协作

- 狼人私聊只在狼人夜间阶段开放。
- 仅存活狼人能够查看和发送消息。
- 支持快捷消息、自由文字和目标建议。
- 自由文字需要限制长度和发送频率。
- 本局狼人消息按服务端序列保存，存活狼人断线重连后可以恢复。
- 消息写入规范化 SQLite 历史；历史查询仍按当前读取者身份裁剪，游戏结束后的公开复盘不展示狼人私聊。
- 新一局开始时清空客户端当前对局消息视图，并创建新的对局会话。
- 主机公共屏幕、其他角色和死亡狼人均不能查看当晚聊天。

### 3.2 击杀投票

- 每名存活狼人可选择任意存活玩家，包括自己和狼人队友。
- 狼人可以选择“空刀”。
- 玩家在阶段锁定前可以取消确认、修改目标并重新确认。
- 全部存活且在线的狼人确认后，阶段提前结束并锁定结果。
- 离线狼人不阻塞提前结束。
- 有在线狼人未确认时，继续等待至超时。
- 未投票狼人视为弃权，不计入任何选项。
- 超时后票数最高项生效。
- 最高票并列时视为空刀。
- 狼人自刀或刀队友属于普通狼人袭击，可以被女巫解救。
- 唯一狼人选择自刀合法。

## 4. 预言家规则

- 每晚可以查验一名其他存活玩家。
- 不能查验自己。
- 可以重复查验以前查过的玩家。
- 确认前可以修改目标。
- 确认后立即得到结果并结束预言家阶段。
- 结果只显示“狼人”或“好人”，不显示具体身份。
- 未来特殊狼人统一显示为“狼人”；村民和神职统一显示为“好人”。
- 离线或超时视为放弃本夜查验。

## 5. 女巫规则

- 解药一局一瓶，毒药一局一瓶。
- 第一夜可以自救，之后不能自救。
- 同一夜不能同时使用解药和毒药。
- 女巫始终能看到当晚狼人袭击目标，即使解药已经用完。
- 狼人空刀时显示“今晚无人被袭击”，此时不能使用解药，但可以使用毒药。
- 女巫不能毒自己。
- 女巫当晚被狼人袭击时仍拥有完整行动权。
- 离线或超时视为不使用药物。

## 6. 夜间结算与公布

### 6.1 守卫规则

- 每晚可守护一名存活玩家，也可以选择空守。
- 可以守护自己，但不能连续两晚守护同一名玩家。
- 空守后，下一夜可以重新守护上一名实际守护过的玩家。
- 守护只抵消狼人袭击，不抵消女巫毒药、白天放逐或猎人开枪。
- 同一晚守卫守护与女巫解救同一名狼人袭击目标时，该玩家存活。
- 守卫不会得知守护是否生效；离场、超时或主机跳过视为空守。

### 6.2 结算

- 所有夜间行动完成后统一结算。
- 多人死亡时统一公布死亡名单，不说明死亡原因。
- 无人死亡时公布“昨夜平安夜”。
- 若死亡猎人可以开枪，先处理猎人技能，再判断胜负和后续流程。

## 7. 猎人规则

- 猎人被狼人袭击或白天放逐死亡时，可以带走一名其他存活玩家，也可以放弃开枪。
- 猎人被女巫毒死时不能开枪；同一夜同时被狼人袭击和毒药命中时也不能开枪。
- 猎人处理完成前，主机不能继续天亮或放逐后的流程。
- 被猎人带走的玩家不触发死亡技能。
- 猎人离场、超时或主机跳过视为放弃开枪；开枪结算后再判断胜负。

## 8. 白痴规则

- 白痴首次成为白天放逐结果时公开身份并免于死亡。
- 翻牌后仍为存活玩家，可以正常发言，但永久失去投票权。
- 翻牌白痴不再作为放逐候选人。
- 白痴被狼人袭击、毒药或猎人开枪命中时正常死亡。

## 9. 遗言规则

- 第一夜所有死亡玩家均可发表遗言，顺序按玩家编号。
- 第二夜及以后夜间死亡玩家没有遗言。
- 白天被放逐玩家始终可以发表遗言。
- 如果死亡或放逐结算后游戏已经结束，则不再发表遗言。
- 遗言时长由主机配置，并可在对局中调整。

## 10. 白天发言

- 玩家按固定编号参与发言。
- 第一天随机决定正序或倒序。
- 之后每天交替发言方向。
- 死亡和离场玩家自动跳过。
- 当前玩家可以提前结束自己的发言。
- 超时后自动切换到下一位。
- 离线玩家经过重连宽限后仍未返回，则跳过本轮发言。
- 正常发言默认 60 秒，主机可在开局前或对局中修改。
- 主机可以单独延长或缩短当前玩家的剩余时间。
- 时间设置最低为 15 秒。

### 10.1 白天公开文字

- 公开文字是现场口头发言的补充，不改变现有发言顺序。
- 房间在开局前选择 `ordered` 有序发言或 `open` 自由讨论模式，开局后不能切换。
- 有序模式下仅当前发言者可以发送 `day-public` 文字，其他玩家和主机只能查看。
- 自由讨论模式下，`day-speech` 阶段所有存活且未离场玩家都可以发送公开文字，但只有当前发言者可以提前结束自己的发言轮次。
- 第一夜死亡玩家和被放逐玩家仅在自己的遗言轮次可以发送。
- 自由讨论模式不放宽遗言权限，`last-words` 始终仅当前遗言者可发送。
- 投票、夜间、结算、游戏结束和其他非发言阶段禁止发送。
- 每条消息由服务端分配唯一 ID 和单调递增序列，客户端按序列排序并按 ID 去重。
- 本局公开文字记录写入 SQLite；刷新、重连或服务恢复后按已见序列增量补发，也可分页加载当前对局公开复盘。
- 新一局开始时创建新的聊天会话，不把上一局消息混入当前时间线。
- 暂停期间即使玩家仍是当前发言者，也禁止发送。

## 11. 白天投票

- 仅存活且未翻牌的白痴以外玩家可以投票。
- 玩家只能投给其他存活玩家，禁止自投。
- 玩家可以主动弃票。
- 未投票、离线或超时统一记为弃票。
- 在投票锁定前，玩家可以取消确认、修改投票并重新确认。
- 全部存活且在线的玩家确认后，投票提前结束。
- 离线玩家不阻塞提前结束。
- 投票期间不显示实时票数或其他玩家选择。
- 投票结束后，手机端和主机端显示完整投票明细及弃票情况。
- 最高票玩家被放逐。
- 最高票平票时无人被放逐，不进行第二轮投票，直接进入下一夜。

放逐流程：

```text
锁定投票
→ 公布完整投票明细
→ 宣布被放逐玩家
→ 立即判断胜负
→ 未结束时被放逐玩家发表遗言
→ 进入下一夜
```

## 12. 胜负规则

采用屠边规则：

- 所有狼人死亡：好人胜利。
- 所有村民死亡：狼人胜利。
- 所有神职死亡：狼人胜利。
- 同一次统一结算中，狼人全部死亡且狼人同时完成屠边：平局。
- 每次夜间死亡、白天放逐或主机强制修正生死后立即判断胜负。

游戏结果使用中文：

- 好人胜利
- 狼人胜利
- 平局
- 对局终止

游戏结束后：

- 立即停止所有发言和操作。
- 公布游戏结果。
- 公开所有玩家身份。
- 展示死亡、查验、用药、投票和主机干预等对局记录。

主机强制结束时结果为“对局终止”，不判定任何阵营胜负。

## 13. 主机干预规则

### 13.1 暂停与继续

- 暂停后所有倒计时冻结。
- 暂停期间公开文字、狼人私聊和其他游戏操作禁止。
- 继续后恢复原剩余时间。

### 13.2 跳过阶段

- 跳过狼人阶段：视为空刀。
- 跳过预言家阶段：视为不查验。
- 跳过守卫阶段：视为空守。
- 跳过女巫阶段：视为不用药。
- 跳过猎人阶段：视为放弃开枪。
- 跳过投票阶段：所有未形成的投票视为弃票。

### 13.3 玩家离场与状态修正

- 主机可等待重连、跳过操作、批准接管、判定离场或强制结束。
- 主机强制修改生死不触发遗言和角色技能。
- 修改后立即判断胜负。
- 所有干预向全体显示并记录，但不得泄露秘密信息。
- 第一版不支持回退到上一阶段。

## 14. 身份确认

- 所有在线玩家确认身份后进入第一夜。
- 有玩家离线或未确认时，主机可以等待、移除玩家或强制开始。
- 强制开始及相关处理必须公开提示并记录。

## 15. AI 玩家

- 机器人占用普通玩家座位，参与人数统计、身份随机分配、生死、夜间行动、发言和投票规则与人类玩家一致。
- 当前仅提供确定性本地机器人，由主机在大厅添加或移除；游戏开始后不能新增机器人。
- 机器人只能根据自身玩家视图行动。狼人机器人可读取合法狼人队友和狼人阶段信息，其他机器人不能读取这些字段。
- 机器人动作必须通过与人类玩家相同的阶段、身份、生存状态、目标和载荷 Schema 校验。
- 机器人不能重连，也不能由新设备接管；服务从快照恢复后机器人保持在线并继续行动。
- 超时、取消、过期状态或适配器异常产生的机器人决策不会执行。
- 当前未接入外部大模型或聊天机器人供应商。
