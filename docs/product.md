# 局域网狼人杀 MVP 产品说明

## 1. 项目背景

本项目是一款用于朋友聚会的局域网狼人杀辅助系统。一台 Windows 电脑作为主机和公共屏幕，玩家手机连接同一局域网后，通过扫描二维码在浏览器中加入房间。

系统负责身份分配、夜间行动、发言计时、投票、胜负判断和断线恢复。玩家在现场直接口头发言，不提供实时语音。

## 2. 核心目标

- 玩家无需安装 App，扫码后使用手机浏览器加入。
- 不依赖互联网或云服务器，可在同一局域网内运行。
- 同一时间只运行一个房间。
- 参赛人数不写死，由主机根据实际玩家和身份配置决定。
- 主机公共屏幕只展示公开信息，不泄露身份和夜间行动。
- 支持玩家刷新、锁屏、暂时断网后的重连。
- 主机拥有处理异常流程和玩家离场的最高管理权。
- 能够从创建房间连续完成一整局基础狼人杀。

## 3. MVP 角色

- 狼人
- 村民
- 预言家
- 女巫
- 守卫
- 猎人
- 白痴

## 4. 用户角色

### 4.1 主机

Windows 电脑运行服务并显示公共页面。主机操作者不通过电脑直接参赛；如需参赛，必须使用手机扫码加入。

主机可以：

- 创建房间并显示二维码和房间号。
- 查看玩家名单、编号及连接状态。
- 调整开局前的玩家顺序和编号。
- 配置角色数量及各阶段时间。
- 开始、暂停、继续或强制结束对局。
- 动态调整后续阶段时间。
- 延长或缩短当前阶段时间。
- 跳过当前阶段并使用该阶段的默认结果。
- 等待玩家重连、跳过其操作、批准新设备接管或将其判定离场。
- 强制修正玩家生死状态。
- 重新开始一局或返回房间调整配置。
- 开局前刷新加入二维码，使旧二维码失效。

第一版不支持回退到上一阶段。所有主机干预都必须记录，并向全体玩家显示操作类型；提示中不得泄露秘密身份和夜间行动。

### 4.2 玩家

玩家使用手机浏览器：

- 扫码并输入昵称加入房间。
- 查看并确认自己的身份。
- 查看自己有权知道的私密信息。
- 执行夜间行动。
- 在狼人阶段进行狼人私聊、提议和投票。
- 查看发言顺序和倒计时。
- 提前结束自己的发言。
- 提交、修改并确认白天投票。
- 断线后恢复原玩家身份和当前页面。

### 4.3 死亡玩家

- 可以继续查看公共流程和投票结果。
- 不得查看存活玩家身份或夜间秘密。
- 不能聊天、投票或执行技能。
- 仅在规则允许时发表遗言。

第一版不提供独立观察者模式。

## 5. 核心使用流程

```text
主机启动服务
→ 创建单一房间并显示二维码
→ 玩家扫码、输入昵称并加入
→ 主机调整玩家顺序、角色数量和时间
→ 主机开始游戏并关闭加入入口
→ 玩家查看和确认身份
→ 夜间行动
→ 夜间统一结算并判断胜负
→ 天亮公布公开结果
→ 遗言及白天发言
→ 白天投票和放逐
→ 判断胜负
→ 进入下一夜或公布游戏结果
```

## 6. 房间与玩家约束

- 同一时间只允许一个房间。
- 同一房间禁止重复昵称。
- 昵称长度为 1 至 12 个字符。
- 玩家按加入顺序自动编号，主机可在开局前调整。
- 开局后玩家编号固定。
- 身份数量总和必须等于参赛人数。
- 配置必须至少包含 1 名狼人、1 名村民和 1 名神职。
- 没有狼人、没有好人或身份数量不匹配时禁止开局。
- 游戏开始后禁止新玩家加入，只允许原玩家重连或经主机批准接管。
- 身份由服务端随机分配，主机不能查看或指定身份。

## 7. 断线与离场

断线不等于死亡或离场。服务端保留玩家身份和状态。

主机可以选择：

- 等待玩家重连。
- 跳过该玩家本轮操作。
- 批准新设备接管该玩家。
- 将玩家判定为离场。
- 强制结束本局。

离场处理不触发遗言或角色技能。主机修正生死后立即重新判断胜负。

## 8. 再来一局

- 保留房间、玩家、编号和房间配置。
- 清空身份、狼人聊天、行动、投票和上一局运行状态。
- 重新随机分配身份。
- 主机也可以先返回房间调整玩家和配置。

## 9. MVP 非目标

第一版明确不开发：

- 正式用户账户、好友、排行榜和云端同步。
- 手机实时语音。
- 在线匹配和公网房间。
- 多房间并行运行。
- 警长和警徽系统。
- 狼人自爆。
- 警长、骑士等其他扩展角色。
- 神秘卡片、身份交换和永久背包。
- 独立观察者模式。
- 阶段回退。
- 无代码角色或规则编辑器。

## 10. 后续方向

当前素材库没有守卫、猎人、白痴或其他扩展角色的正式人物画像，因此这三个角色使用统一空画像占位。后续可另行补充角色图片，并规划更多角色、神秘卡片、玩家档案、对局统计和云端账户。
